- **升级前**：查看 [V4.x 更新日志](./v4.x) 中最新版本的"升级注意"段，确认与当前环境相关的兼容变更（如 API groupVersion 调整、数据库最低版本要求等）；
- **关注新功能**：按版本号浏览 "新增功能" 段，了解是否覆盖你的使用场景；
- **排障参考**：遇到疑似版本相关问题时，回溯对应版本的 "缺陷修复" 段。
