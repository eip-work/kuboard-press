# 套件市场（Addon Marketplace）

本页说明如何在 Kuboard 中通过**套件市场（Addon Marketplace）**一键安装运维组件（如监控、日志、存储、网关等），并在安装后对其进行管理。套件（Addon）安装后会深度集成到 Kuboard 界面中，例如在节点详情页、工作负载详情页出现扩展入口。

::: tip 与 Chart 市场（Helm Marketplace）的区别
Kuboard 有两套市场，容易混淆：

- **套件市场（本页）**：分发 Kuboard 套件（Addon），安装后可深度集成到 Kuboard 界面（扩展入口、快速链接、自带配置页）；
- **Chart 市场（Helm Marketplace）**：浏览并安装通用 Helm Chart，见 [Chart 市场](../../helm/marketplace)。

两者相互独立：通过套件市场安装的资源不会生成 Helm Release；想用 Helm 部署应用，请走 Chart 市场。
:::

## 进入套件市场

1. 在左侧菜单进入 **集群管理 → Kubernetes 集群**，点击目标集群，打开集群详情页。
2. 点击 **Kuboard 套件** 页签（仅当集群状态为就绪时显示）。
3. 页面顶部有两个子页签：

| 页签 | 作用 |
|---|---|
| 已安装套件 | 列出集群中已安装的套件卡片，可进入详情、查找新套件、创建自定义套件 |
| 套件仓库 | 打开套件市场页面，浏览并安装新的套件 |

## 浏览与查找套件

点击 **套件仓库** 页签，页面中会嵌入由 Kuboard 官方套件库在线提供的套件市场。在市场中您可以：

- **浏览**：市场以卡片/列表形式展示全部可用套件，包含名称、版本、更新时间、作者与简介；
- **查找**：通过搜索框按关键字过滤，或按分类浏览；
- **识别已安装**：市场会对本集群已安装的套件做出标记，避免重复安装；
- **开始安装**：在目标套件卡片上点击 **安装**，进入安装流程。

<!-- screenshot-todo: 套件仓库页全貌（内嵌市场页 + 套件卡片 + 搜索/分类） -->

::: warning 离线环境
套件市场页面由外部在线服务提供，浏览器无法访问外网时将不能加载套件仓库列表。可在**具备外网访问条件的浏览器**中打开市场页面链接，按页面提示下载套件相关文件，再回到离线环境完成安装（即离线安装）。
:::

## 安装套件

在市场页点击 **安装** 后，会自动跳转到该套件的详情页。详情页以 1/2/3/4 编号的页签引导您完成安装。

### 步骤 1：套件参数

1. 进入 **1 套件参数** 页签，填写套件要求的参数（如集群名称、存储类 StorageClass 等）。
2. 若套件带有「额外步骤」（安装前需要在集群外手工完成的动作），阅读并完成后勾选 **确认已完成**。
3. 点击 **保存**，向导进入下一步。

### 步骤 2：安装脚本

1. 进入 **2 安装脚本** 页签，页面列出套件将要导入集群的 YAML 对象，可直接查看内容。
2. 带预安装脚本的套件：先点 **预安装**，完成后再点 **安 装**；普通套件直接点 **安 装**。
3. 安装完成后，向导进入下一步。

### 步骤 3：初始化

1. 进入 **3 初始化** 页签，页面会自动检查套件相关 Pod 是否全部就绪（就绪后弹窗提示）。
2. 点击 **执行初始化**，弹窗中以进度条和任务列表展示每个初始化任务的执行结果。
3. 全部任务成功后，**套件正式激活**，其扩展入口、快速链接开始生效。

### 步骤 4：扩展（可选查看）

进入 **4 扩展** 页签可查看套件的扩展入口。激活后，套件会在集群 / 名称空间 / 节点 / 工作负载详情页出现对应入口。

## 安装后的管理

安装完成后，随时可以回到 **集群详情页 → Kuboard 套件 → 已安装套件**，点击某套件卡片上的 **详情** 进入管理页面。

### 快速链接

套件激活后，详情页顶部显示 **套件快速链接** 区域。点击其中的按钮可直接打开套件自带的 Web 界面（通过 Kuboard 代理访问，无需手动暴露 Service）。

### 配置页

部分套件带有**配置**页签（编号 5+，绿色编号）。此类页签在套件激活后出现，用于修改套件的运行参数。

### 禁用 / 启用

进入 **4 扩展** 页签：

- 点击 **禁用套件**，套件的扩展入口随即在 Kuboard 各处隐藏；
- 禁用后，点击 **启用套件** 可恢复。

### 卸载套件

1. 进入套件详情页 **2 安装脚本** 页签，点击 **卸 载**，将套件安装时导入集群的 YAML 对象逐个删除。
2. 卸载完成后，回到详情页点击右上角 **删除套件**，将套件定义一并删除。

::: warning 删除套件有前置条件
- 尚未安装任何工作负载的套件（刚创建或刚填完参数），可直接点击 **删除套件**；
- 已完成安装的套件，必须先按上面的步骤**卸载**其导入的工作负载，否则页面会提示「请先卸载」并阻止删除。
:::

### 创建自定义套件

在 **已安装套件** 页点击 **创建自定义套件**，填写名称空间、id、名称、描述、作者、版本（可用范围默认「集群内可用」，无需填写）后创建套件骨架。创建后进入套件详情页，按 [安装套件](#安装套件) 的向导逐步编写参数与安装脚本——适合将自研组件封装为套件复用。

::: tip 多 Kuboard 实例提示
同一个 Kubernetes 集群可以导入到多个 Kuboard 实例。此时请确保各实例中该集群的**名称一致**，否则部分套件可能无法正常工作。
:::
