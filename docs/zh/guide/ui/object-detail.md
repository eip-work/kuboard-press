# 资源详情页

所有 Kubernetes 资源的详情页都遵循同一套页面结构，页签与操作一致。本页归纳这些共性；各资源的概要内容差异见本指南对应章节。

## 如何打开

在资源列表页点击资源**名称**进入详情页，地址以 `/k8s/` 开头（包含集群、API 组、版本与资源名称）。

## 顶部操作区

| 按钮 | 说明 |
| --- | --- |
| **编辑** | 进入编辑页（该资源有编辑页时显示） |
| **YAML** | 以只读方式查看该资源的完整 YAML |
| **删除** | 删除当前资源 |
| **特有操作** | 资源专属按钮，如 Deployment 的**重启 / 伸缩**、Pod 的**终端 / 日志 / 文件浏览器**，紧邻通用按钮出现 |

标题区还提供指向 [Kubernetes 官方文档](https://kubernetes.io/docs) 的链接（概念说明 + API 参考）。

## 元数据卡片

详情页顶部展示**元数据卡片**（卡片右上角可折叠 / 展开），内容包括：

- 名称、所属集群、名称空间、创建时间、UID、Resource Version 等基本信息；
- **标签（Labels）** 与 **注解（Annotations）**，可展开查看完整键值。

## 页签

详情页主体为页签结构：

| 页签 | 内容 |
| --- | --- |
| **详情** | 资源的概要信息，由各资源自身的组件渲染：例如 Deployment 的副本就绪状态、Service 的端口与端点、HPA 的目标/当前指标等 |
| **YAML** | 该资源的完整 YAML（只读） |
| **关系** | 以图谱形式展示该资源与其它资源的关联（owner、引用、选择器等） |

部分资源（如 Pod）在元数据卡片右侧直接内嵌**事件时间线**，无需切换到事件页即可看到最近事件。

## 事件与变更历史

- **事件**：详情页可查看与该资源相关的 Kubernetes 事件（关注对象过滤），便于排障；
- **变更历史**：展示该资源的修订历史，可查看每次变更的差异；工作负载（Deployment 等）支持从历史版本**回滚**。

## 自动刷新

详情页支持实时更新与自动刷新；在 URL 末尾追加 `?autoRefresh=true` 可让页面自动刷新。
