# 集群管理

集群是 Kuboard 管理的核心对象。本节覆盖从"接入第一个 Kubernetes 集群"到"日常维护连接、同步缓存、跨集群搬运资源"的完整生命周期。

## 快速导航

| 章节 | 内容 | 适用场景 |
| --- | --- | --- |
| [导入集群](./import) | 通过 kubeconfig / ServiceAccount 导入一个新集群 | 首次接入 K8s 集群 |
| [编辑集群](./edit) | 修改集群名称、描述、连接参数、缓存策略 | 调整已有集群配置 |
| [同步状态](./sync-status) | 查看全量 / 增量同步进度、错误日志与重试 | 排障同步卡顿或失败 |
| [资源导入导出](./export-import) | 在集群间批量导入 / 导出 K8s 资源（YAML） | 跨集群迁移、灾备 |

## 推荐阅读顺序

1. **首次接入**：从 [导入集群](./import) 开始，按页面引导填入 apiserver 地址与凭证；
2. **日常维护**：在 [编辑集群](./edit) 中调整缓存策略与默认参数；
3. **排障**：集群列表出现异常时，先看 [同步状态](./sync-status) 定位是同步链路还是连接问题；
4. **跨集群搬运**：使用 [资源导入导出](./export-import) 完成批量迁移。

::: tip 与后续章节的关系
完成 [导入集群](./import) 后，建议继续阅读 [工作负载](../workload/) 章节发布第一个应用；多集群场景下，`auth.clusterIds` 与 `auth.clusterNames`（来自 `useAuthStore`）会决定左侧栏可见的集群清单。
:::
