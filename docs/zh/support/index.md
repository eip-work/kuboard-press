# Kuboard 授权与支持

Kuboard 是基于 Kubernetes 的容器管理平台。本页说明如何获得授权、免费版与增强版的差异，以及获取技术支持与更新动态的渠道。

## License 授权

免费版可管理 3 套 Kubernetes 集群，增强版通过授权文件解锁更多容量与专属服务。两版的核心功能（集群管理、工作负载、存储、网络、Helm、MCP 等）完全一致，主要差异如下：

| 能力 | 免费版 | 增强版 |
| --- | --- | --- |
| 管理集群数 | 不超过 3 套 | 超过 3 套 |
| 操作审计日志 | 仅当天 | 历史日志完整保留 |
| 高可用部署 | 不支持 | 支持 |
| 付费用户专属答疑通道 | 不支持 | 支持 |
| 远程协助 | 不支持 | 支持 |

如何获取与导入授权文件，见 [License 安装](./license-install)。

::: tip 需要授权吗？
仅使用免费版功能、管理不超过 3 套集群时，无需授权即可直接使用；需要增强版能力时再导入授权文件即可。
:::

## 社区与商业支持

免费版用户可通过微信/QQ 社群和 GitHub Issue 获得社区答疑；增强版用户另享专属答疑通道与远程协助。详见 [社区与商业支持](./community)。
