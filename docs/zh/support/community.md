# 社区与商业支持

本文汇总 Kuboard 的社区答疑渠道（免费）与商业支持（付费用户专属），帮助您快速找到合适的问题解决途径。

## 免费支持

| 渠道 | 说明 | 面向 |
| --- | --- | --- |
| **微信 / QQ 社群** | 使用问题答疑、最佳实践交流 | 所有用户 |
| **GitHub** | 在 [kuboard-press](https://github.com/eip-work/kuboard-press) 提交 Issue、反馈问题或 Star 支持项目 | 所有用户 |
| **订阅邮件** | 第一时间获得版本更新与产品资讯 | 所有用户 |

微信 / QQ 社群与订阅入口均可在 [Kuboard 授权与支持](./index) 页面找到。

## 订阅更新动态

在 [Kuboard 授权与支持](./index) 页面底部填写订阅信息，即可订阅 Kuboard 的版本更新动态与产品资讯。

## 商业支持（增强版专属）

| 渠道 | 说明 |
| --- | --- |
| **付费用户专属答疑通道** | 付费用户享专属答疑通道，问题响应更快、更直接 |
| **远程协助** | 在必要时由官方人员远程协助排查、解决问题 |

增强版的完整功能清单与授权方式，请参考 [License 安装](./license-install)。

## 关于授权的获取

商业支持与更多集群容量均通过 Kuboard License 解锁：

- 免费版可免费管理 3 套 Kubernetes 集群；
- 需要管理更多集群或获取商业支持时，购买并导入 [License 授权文件](./license-install) 即可生效。
