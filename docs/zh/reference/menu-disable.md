# 菜单项设置（禁用 K8s 资源入口）

左侧菜单默认展示 56 个 K8s 资源入口，多数团队用不到全部。本页说明管理员如何**全局隐藏（禁用）**某些资源或功能入口，精简左侧菜单。

**适用对象**：管理员。禁用只隐藏菜单入口，不影响集群内资源，也不做权限校验；访问权限控制请用 [RBAC 权限设置](./rbac-scopes)。

## 入口位置

以管理员身份登录，进入 **设置 → 系统设置**，选择页面左侧标签页 **菜单项设置**。进入后自动加载一张与左侧菜单结构一致的资源树，树节点都带复选框，底部是 **保存 / 取消 / 重置** 按钮。

## 界面元素

| 元素 | 含义 |
| --- | --- |
| 复选框 | 勾选 = 显示该入口；取消勾选 = 隐藏该入口 |
| 核心 徽标 | 核心资源（如节点、Deployment），强制显示，不可禁用，也没有复选框 |
| 锁定 徽标 | 不可禁用的非 K8s 菜单项，仅作提示 |
| 搜索框 | 按资源名称（中/英文）快速定位树节点 |

## 禁用某个资源入口

以隐藏"存储卷快照"入口为例（恢复显示操作相反，重新勾选并保存即可）：

1. 在搜索框输入"快照"，或在 **存储** 分组下展开，找到 **存储卷快照**；
2. **取消勾选**其复选框（此时进入待禁用列表，尚未生效）；
3. 点击 **保存**，页面提示"保存成功"；
4. 刷新页面，左侧菜单中该入口消失。

::: tip 未保存时的两个按钮
**取消** 放弃本次勾选改动；**重置** 重新从服务端加载最新配置，都会丢弃未保存的改动（不是恢复出厂默认值）。
:::

## 生效时机

**保存即生效，无需重启服务**，刷新页面即可看到变化。配置对所有人、所有集群统一生效；被禁用的资源本身仍照常运行，只是入口被隐藏。自定义资源（CRD）的动态菜单不受本设置影响。

## 默认禁用项

全新安装首次启动时，以下 5 类低频资源默认隐藏（此后以你保存过的配置为准）：

| 类别 | 默认禁用的资源（共 21 个） |
| --- | --- |
| 存储快照与 CSI | 存储卷快照、存储卷快照类、CSI 驱动、CSI 节点、CSI 存储容量、存储卷挂载 |
| 调度与运行 | 运行时类（RuntimeClass）、PriorityClass、Lease |
| 集群高级组件 | EndpointSlice、PodDisruptionBudget、FlowSchema、PriorityLevelConfiguration |
| 准入控制 | Mutating/Validating Webhook 配置、ValidatingAdmissionPolicy 及其绑定 |
| DRA（动态资源分配） | ResourceClaim、ResourceClaimTemplate、ResourceSlice、PodSchedulingReadiness |

默认隐藏同样只隐藏菜单入口。例如默认隐藏的"存储卷快照"，需要时取消勾选并保存即可恢复，相关操作见 [存储卷快照与 CSI](../guide/config-storage/snapshots-csi)。

## 典型使用场景

- **精简左侧菜单**：只用 Deployment、Pod、Service 等常用资源时，把 RuntimeClass、FlowSchema、Lease 等高级低频资源统一取消勾选并保存。
- **隐藏未部署的 CSI 快照入口**：未安装 CSI 快照插件时，"存储卷快照"等入口点击后为空或报错，直接禁用。
- **隐藏低频功能入口**：[Helm Release](../helm/releases)、[资源全景图](../guide/ops/resource-map)、集群"常用操作"等入口可一并隐藏。

## 注意事项

- **核心资源不可禁用**：带"核心"徽标的资源没有复选框，始终显示。
- **禁用不等于权限控制**：隐藏入口的路由仍然存在，知道完整 URL 的用户仍可访问；彻底阻断请用 RBAC。
