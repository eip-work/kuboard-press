# 使用 Kuboard V4

本节按"日常使用一个 Kuboard 实例"的用户旅程组织文档：

- **集群管理**：导入、编辑、同步状态、资源导入导出
- **工作负载**：Deployment / StatefulSet / DaemonSet / Job / CronJob / Pod / HPA / 持续部署
- **配置与存储**：ConfigMap / Secret / PVC / PV / StorageClass / CSI
- **服务与网络**：Service / Ingress / NetworkPolicy / Gateway API
- **集群资源**：Node / Namespace / Quota / LimitRange / PDB / Scheduling / Admission / FlowControl / DRA
- **自定义资源**：CRD 与 CR
- **运维可视化**：事件、资源全景图、套件市场
