## How to Read

- **Before upgrading** — read the "Upgrade Notes" section for the target version in [V4.x Changelog](./v4.x), and check any compatibility changes that affect your environment (API groupVersion shifts, minimum database version, etc.);
- **New features** — browse "New Features" by version to see if a recent release covers your scenario;
- **Troubleshooting** — when a problem looks version-related, jump back to the "Bug Fixes" section for the matching version.

::: tip Release cadence
Kuboard V4 iterates continuously, adding features and tracking the latest GA Kubernetes releases (currently K8s 1.15 - 1.34). Regular upgrades are recommended to pick up the latest compatibility fixes and features.
:::
